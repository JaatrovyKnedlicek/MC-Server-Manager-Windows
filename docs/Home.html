MC Server Manager

MC Server Manager is a lightweight and simple tool built for players who want to host their own local PaperMC server with ease. Forget about complex terminal commands or manual configurations — set up and manage your server in just a few clicks. The easiest way to play Minecraft with your friends, hassle-free.
